# 星语实验 · 施测说明（仅施测者看）

本实验测"人如何学会一个新规则、以及学会的是什么"。被试不需要任何语言学或数学背景。

## 流程

1. **学习相（≤25 分钟）**：把《学习页》交给被试。按页上指示：先猜后对答案。施测者口头反馈"对/错"即可，不解释规律（无论被试怎么问，都只说"再看看例子"）。被试自认学会后进入考试；未到 25 分钟也可提前，记录实际用时：____ 分钟。
2. **休息（2 分钟）**：收走学习页。
3. **考试一（≤10 分钟）**：《考页》第一部分（12 题 + 文字题）。不给任何反馈。到时间即收，未完成的题记 0。
4. **考试二（≤10 分钟）**：第二部分（8 题）。密码表就在考页上，可随时查看。不给反馈。

## 计分（施测后填）

答案：考试一 1-3 um，4-6 is，7-9 is，10-12 ok；考试二 14-15 um，16-19 is，20-21 ok。
