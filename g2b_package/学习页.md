# 星语 · 学习页

外星球"星语"里，名词有单数和复数两种形式。下面 16 个单词展示了单数→复数的变化。

## 你的任务

通过这 16 个例子，弄懂星语名词变复数的方法。学完之后你要用同样的方法处理没见过的新单词。

## 学习方式

1. 先遮住右列，自己猜每个词的复数；
2. 然后对照答案，猜对了打勾，猜错了改正；
3. 可以反复过这 16 个词，直到你觉得自己掌握了规律；
4. 时间最多 25 分钟。学会后告诉施测者。

## 例子（16 个）

| 单数 | 复数 |
|---|---|
| bab | babum |
| kad | kadum |
| pag | pagum |
| dab | dabum |
| big | bigis |
| pid | pidis |
| gub | gubis |
| bud | budis |
| kap | kapis |
| tap | tapis |
| bap | bapis |
| pak | pakis |
| buk | bukok |
| dup | dupok |
| dik | dikok |
| tup | tupok |

## 说明

- 星语的字母表只有这 9 个字母：b d g k p t a i u。所有单词（包括考试里的）都只用这些字母。
- 考试时没有反馈，也没有新的例子。祝顺利。
