# 直觉机制 · 人类被试实验包（G2）

**目的**：把程序在 LLM 上测出的三个核心现象，在人类专家身上做对照实验。
**被试**：数学系学生或以上，n ≥ 5（理想 n = 10）。
**时长**：每人约 25-35 分钟（三份考卷连续作答）。
**施测规则**：三份考卷按 1→2→3 顺序，不可回看，不可讨论；考卷 2 前无任何提示。

---

## 考卷 1：落域规则发现（对应 LLM 实验 P205/P198）

**背景故事（给被试）**：某族数学对象带一个参数 d。对某些特殊的 d，一个
相关的量会"恰好落在干净的位置"（术语见下）。给你 8 个已判定的例子：

| d | 判定 |
|---|---|
| 4 | CLEAN（二次落域，s=3） |
| 8 | CLEAN（二次落域，s=6） |
| 12 | ordinary |
| 20 | ordinary |
| 28 | ordinary |
| 40 | ordinary |
| 140 | ordinary |
| 220 | ordinary |

**问题 1a**：用一句话写出判定规则。
**问题 1b**：这条规则适用于所有同族数据吗？（适用 / 仅限上表类似情形 / 不确定）
**问题 1c**：预测以下新行（同族）：d = 52, 68, 308, 9, 18, 27, 45, 63 —— 各是 CLEAN 还是 ordinary？

> 计分：1c 中 9, 18, 27, 45, 63 的预测是**新颖性门**（真值：全 ordinary）；
> 若被试从 8 个例子外推出错误规则（如"CLEAN ⟺ d=4·素数"），会在此暴露。
> 对照 LLM 结果：deepseek 同题型 PASS-STRONG，doubao FAIL。

## 考卷 2：遮蔽重放（对应 P189/P218——坐标轴遮蔽）

**给被试**：下面 8 个数值序列来自"特殊"与"普通"两类数学对象
（**参数值已隐藏**，只显示对象的一个可观测量）：

```
  0.005000 / 0.180672
  0.009615 / 0.200000
  0.031250 / 0.238095
  0.050000 / 0.250000
  0.083333 / 0.250000
  0.125000 / -9.680667
  0.016708 / 0.217853
  0.000000 / 0.024768
```

**问题 2a**：哪些对象属于"特殊"类？（写出序号或数值）
**问题 2b**：你的判断依据是什么？
**问题 2c**：如果允许你问一个额外的数值（任意一个和这些对象相关的量），
你想问什么？

> 计分：2a 前六个是 SPECIAL、第七个是近整数陷阱（0.016708 = d=13 类的
> 邻近影子）、第八个是 ordinary。2c 的答案分类：问参数轴（d / x0 的来源）
> = 机制导向；问表面特征 = 表面导向。
> 对照 LLM 结果：两模型遮蔽后均崩（P218）；人类预期至少部分被试要求看 d。

## 考卷 3：语言化鸿沟（对应 P170-P184）

**给被试**：回想你在考卷 1 中写下的判定规则（问题 1a）。
**问题 3a**：假设另一位研究者完全按你写的规则（逐字）去判断一个全新的
数据集。你认为他得出的判定和你的直觉判断会一致吗？（完全一致 / 大致一致 /
会有出入）
**问题 3b**：如果可能有出入，出入会出现在什么样的数据上？

> 计分：对照被试的 1a 规则与其在 1c 的实际预测——**人类版语言化鸿沟**：
> 陈述规则与操作行为的偏离率。LLM 对照值：复杂规则 50-100pp、简单规则 0pp
> （P184）。

## 施测与数据回收

1. 考卷以本文档打印或屏幕发放；答案写入配套 `answer_sheet.md`（或任何表格）。
2. 回收后填入 `human_package/results.csv`（列：subject_id, q1a, q1b, q1c_*
   (8 行), q2a, q2b, q2c, q3a, q3b）。
3. 数据回填后由程序自动计分：
   - 新颖性门通过率（对照 LLM 的 STRONG/WEAK/FAIL 三档）
   - 遮蔽考试准确率（对照 LLM 的 0.25 崩溃）
   - 语言化鸿沟偏离率（对照 LLM 的 50-100pp）
4. 每项与 LLM 结果的差异就是"直觉同构公理"的第一批人类检验点。

**答案键**：`answer_key.json`（施测者持有，不对被试公开）。
