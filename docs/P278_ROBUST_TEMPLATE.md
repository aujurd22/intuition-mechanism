# P278: 鲁棒模板聚合——P277 P-real-3 的失败是"中心模板打到背景"吗？中位数聚合能修吗？

**状态**：已完成（2026-10-26）。P-tmpl-4/1/3 PASS，P-tmpl-2 FAIL（单例未修）。总体 MIXED。
`p278_verdict.json` 为机读结论，`p278_preregistration.json` 为跑前注册（先注册后跑，判据未动）。

## 问题

P277 的 P-real-3 FAIL 有两个 `geometry_error` 不在预注册枚举内：Lampshade1 黄板
（rel 67%）、Monopoly 木块（rel 84%）。事后的解释是"bbox 中心模板落到了背景/别的
深度层"。P278 把这句话变成可测量的主张，并测一个零成本的机械修法。

**不用任何模型调用**：复用 P277 记录在案的 VLM bbox 与图像，只改模板选择策略。

## 设计

- 队列：P277 的 14 条 SL 行（有 bbox 且有 rel_err）＝ 12 条通过（对照）+ 2 条
  `geometry_error`（靶子）。P277 的 6 条无 bbox 行按构造不在范围内。
- 估计器：80×80 模板（与 P277 同尺寸）；在 bbox 内 3×3 网格取样 9 个候选中心
  （0.25/0.50/0.75 分数位），NCC 搜索与 P277 完全一致（视差 −40..520 步长 2，
  再 ±3 精修）；**聚合 = 中位数**，**离散度 = MAD**。
- GT：沿用 P277 记录的 `Z_gt`（在 bbox 中心采样），**不重采**——目标深度与 P277 相同。
- 判据：与 P277 相同的操作门槛 0.15。

## 预注册判据与结果

| 预言 | 内容 | 判定 | 数字 |
|---|---|---|---|
| P-tmpl-4 | 复现闸门：中心模板重算应复现 P277 记录的视差 ±1 px，否则全案 INCONCLUSIVE | **PASS** | 14/14 行，max \|diff\| = **0 px** |
| P-tmpl-1 | 机制：两条失败行的中心模板在自身 3×3 网格内是离群值（\|d_c−median\| > 3×MAD），对照行至多 1 条例外 | **PASS** | 板：216 vs 中位 101（MAD 30）；木块：421 vs 中位 71（MAD 89）；对照离群 **0/12** |
| P-tmpl-2 | 修法：中位数让两条失败行都 < 0.15 | **FAIL** | 木块 0.835 → **0.0215**（修好）；板 0.671 → **0.2963**（仍不合格） |
| P-tmpl-3 | 无回归：12 条对照全部保持 < 0.15，且 \|Z_med−Z_c\|/Z_gt ≤ 5% | **PASS** | 回归 0/12；最大偏移 **3.94%**（干净目标上中位数约让视差移动 2 px） |

## 读法（这是本次真正的结论）

1. **机制被证实**：中心模板确实是自身 bbox 内的离群测量，而健康的 bbox 一条都不是。
   所以 P277 的 P-real-3 失败**不是**渲染层或 LLM 的问题，是模板选点策略的机械缺陷。
2. **修法只修了一半，而原因写在配方里**：竖直木块（bbox 主体就是物体）被中位数修好
   （0.835 → 0.0215）；薄黄板（近乎侧视）只从 0.671 拉到 0.2963。9 个模板的视差是
   `[71, 72, 72, 220, 216, 211, 71, 101, 101]`，而 GT 视差是 **71.1 px**——**正确值在
   4 个模板里出现过**，但排序后中位数落在第 5 个值 101（桌面/背景层）。
   换句话说：**物体信号一直在场，是聚合规则把它投掉了**；中位数在"背景模板占多数"
   时只是背景的稳健估计。
3. **代价可见但可接受**：干净目标上中位数系统性地把视差拉低约 2 px（157→151、
   132→129），相对深度偏移最大 3.94%，全部仍通过。
4. **事后描述（不参与判定，登记在 `p278_verdict.json` 的 `post_hoc_descriptive`）**：
   14 行里每一行都至少有一个模板落在 GT 视差 ±5 px 内。Monopoly 的 bbox 只有 101 px
   宽，只有 3 个模板放得下（`[-18, 421, 71]`），中位数取中值 71 恰好稳健——这依赖
   运气而不是设计，要在 P279 里用更稳的聚合（按深度层聚类/取众数）替代。

## 预注册缺口与偏差（如实登记）

- **缺口**：3×3 网格要求 80×80 窗口完整落在 bbox 内；Midd2 黄色角件的 bbox 是
  96×48 px，任何网格点都放不下。**处理方式（未动任何阈值）**：退回 P277 的中心
  模板（median == centre），按零变化对照计入。
- **偏差**：本次在 DSH 自带 Python（numpy 2.3.5 / Pillow 12.3.0）上跑，不是 P277
  当时的宿主环境；允许比较的依据是 P-tmpl-4 复现闸门——它以 0 px 全通过。

## 下一步（P279 候选，不是本实验的结论）

薄/侧视物体需要**物体掩码**而不是更好的聚合器：bbox 内前景/背景分层（例如按
深度层一致性或颜色聚类选模板，而不是在 bbox 内均匀取样），或者在 P-real-3 的
枚举里显式加入 `bbox_majority_background` 这一类。两者都要先注册后跑。

## 主结论

> "bbox 中心模板打到背景"**测得成立**；"中位数聚合"**部分有效**（污染但仍以物体
> 为主体的 bbox 可救，薄物体不可救）。P277 的 P-real-3 FAIL 维持原判，不被推翻。
