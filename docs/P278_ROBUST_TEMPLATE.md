# P278: 鲁棒模板聚合——P277 P-real-3 的失败是"中心模板打到背景"吗？中位数聚合能修吗？

**状态**：已完成（2026-10-26），**经独立只读复核后修正为 v2**：
P-tmpl-4 PASS、P-tmpl-1 **PARTIAL**、P-tmpl-2 FAIL、P-tmpl-3 PASS（11 条可评估对照），总体 **MIXED**。
`p278_verdict.json` 为机读结论（含冻结哈希与 A1–A6 修正登记），
`p278_preregistration.json` 为跑前注册（**冻结未改**，sha256 记在 verdict 里）。

## 问题

P277 的 P-real-3 FAIL 有两个 `geometry_error` 不在预注册枚举内：Lampshade1 黄板
（rel 67%）、Monopoly 木块（rel 84%）。事后的解释是"bbox 中心模板落到了背景/别的
深度层"。P278 把这句话变成可测量的主张，并测一个零成本的机械修法。

**不用任何模型调用**：复用 P277 记录在案的 VLM bbox 与图像，只改模板选择策略。

## 设计

- 队列：P277 的 14 条 SL 行（有 bbox **且**有 rel_err）＝ 12 条通过（对照）+ 2 条
  `geometry_error`（靶子）。范围外的 6 行 = **5 行没有 bbox**（edge_clipped / parse）
  + **1 行有 bbox 但没有 rel_err**（Bowling1 白瓶，degenerate_disp，−26 px）——排除
  依据是缺 rel_err，不是缺 bbox。
- 估计器：80×80 模板（与 P277 同尺寸）；在 bbox 内 3×3 网格取样 9 个候选中心
  （0.25/0.50/0.75 分数位），NCC 搜索与 P277 完全一致（视差 −40..520 步长 2，
  再 ±3 精修）；**聚合 = 可用模板的中位数**，**离散度 = MAD**。
- 实际模板数：**112 次匹配**（12 行 × 9 + Monopoly × 3 + Midd2 × 1），不是 14×9=126。
- GT：沿用 P277 记录的 `Z_gt`（在 bbox 中心采样），**不重采**。
- 判据：与 P277 相同的操作门槛 0.15。

## 预注册判据与结果

| 预言 | 内容 | 判定 | 数字 |
|---|---|---|---|
| P-tmpl-4 | 复现闸门：中心模板重算复现 P277 记录 ±1 px，否则全案 INCONCLUSIVE（**短路**，不评其余） | **PASS** | 14/14 行，max \|diff\| = **0 px**；另用扰动测试验证短路（+5 px → 全部 NOT SCORED / INCONCLUSIVE） |
| P-tmpl-1 | 机制：两条失败行的中心模板在自身网格内是 \|d_c−median\| > 3×MAD 离群值，对照至多 1 例外 | **PARTIAL** | 注册规则下 2/2 命中、对照 **0/12**；但一过有效性检查（见下）木块不再是离群 → 只有板成立 |
| P-tmpl-2 | 修法：中位数让两条失败行都 < 0.15 | **FAIL** | 木块 0.835 → 0.0215（全模板）/ **0.717**（剔非法样本后）；板 0.671 → 0.2963 |
| P-tmpl-3 | 无回归：可评估对照保持 < 0.15 且偏移 ≤ 5% | **PASS** | 可评估 11/11 通过、回归 0；最大偏移 3.94%（157→151，−6 px）；Midd2 为同义反复（median≡centre）**不计入通过数** |

## 读法（修正后的结论）

1. **机制只成立一半**：注册规则下两条失败行的中心模板都是离群测量，但木块那一条
   **依赖一个物理上不可能的样本**——`-18 px` 视差在正基线校正立体里不存在，是匹配器
   打到背景时的伪值。把它剔除后，木块网格只剩 `{71, 421}` → 中位 246、MAD 175，
   |421−246|=175 < 525 → **不再是离群**。因此机制结论降级为 **PARTIAL：薄板成立，
   木块不成立**。
2. **"打到背景"这个说法本身没有被测量**：中心模板给出 216 px / 421 px，对应
   0.99 m / 0.51 m，而 GT 是 3.01 m / 3.08 m，且 NCC 只有 0.435 / 0.574——数据能说的是
   **"中心模板匹配到了一个更近的、低置信度的面"**，至于是背景还是前景遮挡物，本实验
   无法区分。措辞已按此更正。
3. **修法部分有效，原因写在配方里**：竖直木块在"全模板"口径下被中位数修好
   （0.835→0.0215），但在剔除非法样本后其视差中位变 246 px、相对误差 0.717，仍不合格；
   薄黄板的 9 个模板是 `[71,72,72,220,216,211,71,101,101]`、GT 视差 **71.1 px**——
   **正确值在 4 个模板里出现**，但排序后中位数落在第 5 个值 101。也就是说：
   **物体信号在场，聚合规则把它投掉了**；中位数只对"背景占少数"的 bbox 稳健。
4. **代价**：干净目标上中位数平均让视差移动 **−1.3 px**，最大两个是 −6 px（157→151）
   与 −3 px（132→129），相对深度偏移最大 3.94%，全部仍通过。
5. **事后描述（不参与判定，登记在 `post_hoc_descriptive`）**：112 次匹配里，每一行都
   至少有一个模板落在 GT 视差 ±5 px 内；Monopoly 只有 3 个模板放得下（一列），
   中位数取 3 值中的中值恰好稳健——**靠运气，不是靠设计**。

## 独立复核与修正（v1 → v2）

一个只读复核代理独立重写了 NCC 匹配（30 个位置 max diff **0 px**，与本次一致），
同时抓出 7 处问题，全部已修并登记为 A1–A6：

| # | 复核发现 | 处理 |
|---|---|---|
| 1 | **闸门条款未实现**：脚本算完 gate 却无条件评 P1–P3；`declared_deviation` 里的 "passed" 是硬编码字符串 | 已改成短路：gate 失败 → 全部 NOT SCORED、overall INCONCLUSIVE；文本动态生成；并用 +5 px 扰动测试**双向验证**（改前 MIXED，改后 INCONCLUSIVE） |
| 2 | 未注册的 `MAD==0 → Δ≥2` 分支 | 删除，回到注册规则 `\|Δ\| > 3×MAD` |
| 3 | Midd2 的 median≡centre 是同义反复，删除后 P-tmpl-3 会翻 | 改为"不可评估"并从通过数中剔除（不是当作胜利）；P-tmpl-3 由 11 条可评估对照支撑 |
| 4 | **`-18 px` 不可能样本**让木块被判离群 | 增加事后有效性检查（视差必须 ≥0），据实把 P-tmpl-1 降为 PARTIAL |
| 5 | "打到背景"是未测量的措辞 | 改为"更近的低 NCC 面（0.99 m / 0.51 m vs GT 3.01/3.08 m）" |
| 6 | "6 行无 bbox"、"14×9"、"约 2 px" 三处措辞错 | 改为 5 行无 bbox + 1 行无 rel_err；112 次匹配；平均 −1.3 px（最大 −6/−3）|
| 7 | 没有可核对的冻结哈希 | verdict 里记 `prereg_sha256` 与 `raw_sha256`；`registry_check.py` 新增 P278 断言（闸门 0 px、两个 rel 数、模板组成 9/3/1、哈希一致） |

## 预注册缺口与偏差（如实登记）

- **A1 缺口**：3×3 网格要求 80×80 窗口完整落在 bbox 内；Midd2 黄色角件 bbox 96×48 px
  放不下任何网格点 → 退回中心模板（median≡centre）。**未动任何阈值**，该行按不可评估处理。
- **A2 事后有效性**：负视差在正基线校正立体中不可能；剔除后木块的机制结论不成立，
  故 P-tmpl-1 降为 PARTIAL（这一条是**削弱**自己的结论，不是加强）。
- **环境偏差**：本次在 DSH 自带 Python（numpy 2.3.5 / Pillow 12.3.0）上跑；允许比较的
  依据是 P-tmpl-4 闸门以 0 px 通过，且独立实现复算同样 0 px。

## 下一步（P279 候选）

1. **按深度层聚类/取众数**替代中位数（正确值总在模板集里，问题在投票规则）；
2. 或把 `bbox_majority_background` **显式加进 P-real-3 的类别枚举**，承认它是一类
   机械可归因而非必须修掉的 bug；
3. 两者都要先注册后跑，且判据里必须包含"负视差/非法样本"的有效性条款。

## 主结论

> **"中心模板是离群测量"在薄板上成立、在木块上不成立**（后者依赖非法样本）；
> **"中心模板打到背景"没有被测量**（只能说匹配到更近的低置信度面）；
> **"中位数聚合"部分有效**（背景占少数时可救，薄物体不可救）。
> P277 的 P-real-3 FAIL 维持原判，不被推翻。
