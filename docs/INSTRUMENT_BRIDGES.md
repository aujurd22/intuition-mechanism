# INSTRUMENT_BRIDGES.md — 跨仪器预测注册表

缺的是"仪器 A 的输出预测仪器 B 的输出"的定量桥——每建一座桥，仪器收藏就向机制理论移动一寸。

## 桥 1（已焊）：密度恒等式 → 门分档

P225 影子密度公式 `shadow_count(W) = 2^(12−|R(W)|)` 预测 P205 门上
"窗内正余数覆盖不全（k < 2）→ FAIL / PARTIAL，覆盖全 → PASS-STRONG"。

**状态**：✅ 已定量。d=5 的 k 由窗覆盖决定，deepseek 的 PASS-STRONG 恰在覆盖
条件满足时出现；doubao 的 FAIL 模式（s=9 外推）正是密度公式里"未观察余数
自由度"的行为表现。

## 桥 2（已焊）：遮蔽控制 → 门判定的正交分解

P218 遮蔽控制（d 轴藏起）证明 PASS-STRONG 也是 d 值绑定记忆
（0.25 崩塌，零诚实 NEED-D）——**遮蔽轴与门轴正交**：门测迁移自觉、
遮蔽测表示绑定。完整新颖性评估 = 两轴联合（P205 门 + P218 遮蔽）。

**状态**：✅ 正交性已实验确认（P218：双模型崩塌且零 NEED-D）。

## 桥 3（部分）：素因子分解 → grokking 表示组织

P219 Mantel 分解（mod4 +0.454 已学 / mod3 −0.266 未学）确认了 mod-12
表示按 mod-4 分量组织。但 P229-b 5 种子扩展**撤回了可学习性分级**
（mod-4 0.807 vs mod-3 0.800 无显著差异）——素因子分解作为表示分析
有效，但"实特征标比分级易学"的难度分级解读已撤回。

**状态**：⚠️ 表示分析有效，难度分级撤回。

## 桥 4（部分）：倒 U 剂量曲线 → 强模型受害

P227 倒 U 曲线回答"为什么强模型受害"——高剂量端（注意力稀释）
对任何模型都有害。预测：低剂量（~1 条注记）下 glm 不受害甚至微受益（待检验）。

**状态**：⚠️ 预测已注册，低剂量 glm 对照待跑。

## 桥 5（待建）：计价器 ↔ 特征标分级

P210 计价器测的"切换价格"应追踪特征标分级——
decimal→modular 的切换价格（+0.977 on modular task / −0.553 on census）
应与"两任务真规则群的表示论距离"相关。桥的定量形式：切换价格 ≈
α·(群表示论距离) + β。**验证实验**：构造第三个任务（真规则群已知且表示
论距离可算），测切换价格是否落在预测上。

## 桥 7（锚点已建，定量待域重设计）：物种×域不透明度 ↔ 表征缺失

P235 人类首测（n=1 设计试点）：六行域考卷对非数论 CS 背景人类**完全不透明**
（被试做完全部题目但自报不理解任务在问什么），而 LLM 在同一域上有真实部分透明性
（deepseek PASS-STRONG，P205）。桥的定量形式：**opacity(species, domain) =
该物种缺失该域所需表征的程度**——LLM 语料给了它相当于数论训练的先验表征，
人类没有。这把 P235 从考卷事故升格为**边界地图的人类侧锚点**：不透明度不对称
本身是"直觉=特定表征空间中训练出的识别"的跨物种证据。

**可检验预测**：(a) 域重设计为可学会域（人机同学同批示例）后，物种间不透明度差
应消失，P234 的遮蔽不对称预测才可测；(b) 数论训练被试（路线 b）的不透明度应随
表征习得程度分级下降。当前状态：锚点已建（n=1），两个预测都等 G2 重设计域。

## 桥 6（已焊）：grokking 相变 ↔ 发现回路的"啊哈"时刻

P215 曲线分析：最陡 25-epoch 测试增益 +0.655 at epoch 3475；train 1.0 @ epoch 25
→ test 0.9 @ epoch 2925（记忆与泛化间隔 2900 epochs）。发现回路的对应物：
回路轮次-准确率曲线中的跳变点（"啊哈"时刻）应为同一表示重构现象。
