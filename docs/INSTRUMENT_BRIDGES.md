## 桥 1（已焊）：密度恒等式 → 门分档

**桥**：P225 影子密度公式 `shadow_count(W) = 2^(12−|R(W)|)` 预测 P205 门上
"窗内正余数覆盖不全（k < 2）→ FAIL / PARTIAL，覆盖全 → PASS-STRONG"。

**状态**：✅ 已定量。d=5 的 k 由窗覆盖决定，deepseek 的 PASS-STRONG 恰在覆盖
条件满足时出现；doubao 的 FAIL 模式（s=9 外推）正是密度公式里"未观察余数
自由度"的行为表现。

## 桥 2（已焊）：遮蔽控制 → 门判定的正交分解

**桥**：P218 遮蔽控制（d 轴藏起）证明 PASS-STRONG 也是 d 值绑定记忆
（0.25 崩塌，零诚实 NEED-D）——**遮蔽轴与门轴正交**：门测迁移自觉、
遮蔽测表示绑定。完整新颖性评估 = 两轴联合（P205 门 + P218 遮蔽）。

**状态**：✅ 正交性已实验确认（P218：双模型崩塌且零 NEED-D）。

## 桥 5（待建）：计价器 ↔ 特征标分级

**待建**：P210 计价器测的"切换价格"应追踪 P221-b 的特征标分级——
decimal→modular 的切换价格（+0.977 on modular task / −0.553 on census）
应与"两任务真规则群的表示论距离"相关。桥的定量形式：切换价格 ≈
α·(群表示论距离) + β。**验证实验**：构造第三个任务（真规则群已知且表示
论距离可算），测切换价格是否落在预测上。

## 桥 6（已焊）：grokking 相变 ↔ 发现回路的"啊哈"时刻

## 桥 6 结果（已焊）：grokking 相变 = 发现回路"啊哈"时刻的同类物

**分析完成（零调用）**：P215 曲线的最陡 25-epoch 测试增益 = **+0.655 at epoch 3475**
（从 0.24 到 0.90 的跳变窗口 3400-3475）。train 1.0 @ epoch 25 → test 0.9 @ epoch
2925——**记忆与泛化间隔 2900 epochs**。发现回路的对应物：回路轮次-准确率曲线中的
跳变点（"啊哈"时刻）应为同一表示重构现象——桥的定量形式：跳变点的对数速率
（bits/epoch）应与 grokking 相变速率同阶。
