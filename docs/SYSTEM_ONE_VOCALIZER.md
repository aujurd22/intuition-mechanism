# System-One Vocalizer：直觉生成语言的架构设计

**状态**：设计文档 + 原型已实现（P272）。回答的问题：直觉可以生成语言吗？
架构可以完全不同吗？

## 一、来自自身数据的硬约束：语言化鸿沟

P170-184 的实测定律：**直觉知识与语言能力部分脱钩**——模型把判题规则说成
语言再执行，复杂规则只有 25-50 分（纯机遇）。推论：

- 直觉核**可以**输出：判断、结论、置信度、证据指针（浅层，已验证）；
- 直觉核**不可以**可靠输出：深层操作规则的内省解释（会失真为影子）。

因此任何"直觉快速输出"架构必须**绕开内省**：语言承载"判断+证据指针"，
不承载"我按什么规律想的"。

## 二、三级架构光谱

| 级 | 形态 | 状态 |
|---|---|---|
| 1 | 类型化判断直出（nou/choice/score+校准），零开放语言 | **已存在**——Microsoft Decision-1（v1/systemone，9B 后训练）；我们的 intuition_pack（非 transformer：包+验证器+校准映射，0.37ms，ECE 0.0075） |
| 2 | 直觉核定稿判断 + 小模型**渲染**语言 | **本原型（P272）**——LLM 降级为声带 |
| 3 | 非 transformer 核直接生成开放新语言 | **开放问题**——撞语言化鸿沟深处，无已知架构 |

## 三、第二级架构（本原型）

```
现在的栈：  LLM 是大脑（边想边说，每步数千思考 token，分钟级）
提出的栈：  直觉核是大脑（机械路由→检索→验证→校准，毫秒级）
            LLM 是声带（把定稿判断渲染成流畅语言，短输出）
```

流程（全部复用现有组件）：
1. **机械路由**：`route_text` / CognitiveBooth 判域（零 LLM）；
2. **机械验证**：`run_verifier`（zone-1 域，50 位精度证书）；
3. **校准**：三带判定 + 置信度（P142：近整数陷阱→弃权）；
4. **渲染**：glm（effort=minimal）把定稿判断渲染成通顺中文，
   提示词**禁止添加任何新事实主张**——语言接地性由此保证。

## 四、可检验预言（P272）

- **P-vocal**：渲染层输出质量对判断复杂度**不敏感**（渲染的是定稿判断），
  而"内省解释"的输出质量随复杂度**衰减**（P184 预言）。
  若渲染质量也塌——直觉核泄漏了不该泄漏的内省，架构要改。
- **P-ground**：渲染文本的每个事实主张可追溯到验证器证据（零新增主张）。

## 五、对照

| | Decision-1 | System-One Vocalizer（本原型） |
|---|---|---|
| 直觉核 | 9B 神经网络（后训练） | 非 transformer（包+验证器+校准，结构生长） |
| 输出 | 校准概率（typed） | 校准判断 + 渲染语言（接地） |
| 速度 | 快（小模型直出） | 快（核毫秒级+渲染秒级） |
| 证据 | 无（纯校准） | 每句可追溯（验证器证书链） |
| 进化 | 重训 | 结构生长（错误池/包/验证器注册表） |

果蝇脑呼应：投射神经元（随机扩张）→ KC（k-WTA 稀疏化）→ MBON（读出直出
行动）——读出层不生成语言直接生成行动，整个回路无 transformer。本原型的
检索层=扩张层、稀疏匹配=KC、模板渲染=MBON。flypoet 已证 k-WTA 在小
transformer 可行（MBNA 线）。

## 六、边界

- 渲染层仍是一个（小）transformer——"完全无 transformer"的第三级是开放
  问题；
- 渲染层若被要求超出判断内容（写诗、长文），接地性保证失效——声带只在
  定稿内容上工作；
- 开放域（无验证器无包）自动落入 SPECULATION+扫描候选（认知收费站路由），
  不会伪装成直觉。
