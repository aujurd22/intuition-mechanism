# 影子统一定理（Shadow Unified Theorem）

**状态**：框架已建立，数值验证完成（P225 精确恒等式 + P226 偏好定理 + P231 生成侧钻裂缝 + P232 收费站拦截）。论文脊柱。

## 定理陈述

**设定**：假设空间 H、真规则 r ∈ H、观察窗 W（有限样本集 S ⊂ 全域）、
MDL 选择器（按描述长度 + 经验误差字典序选规则）。

**定义**（影子规则）：h′ ∈ H 是 r 的影子，当且仅当
  (1) h′|W = r|W（窗内行为完全一致）
  (2) |h′| < |r|（描述更短）

**定理 1（影子必然性，P225）**：若 H 中存在 h′ 满足 (1)(2)，则任何有限窗 W 下影子数 > 0。
  对周期 m 分类任务：影子数 = 2^(m - |R(W)|)，其中 R(W) = 窗内观察到的余数类集合。
  数值验证：200/200 随机窗精确匹配。

**定理 2（偏好定理，P226）**：MDL 后验众数 = 最短影子 S_r ∩ R(W)。
  严格短于真规则当且仅当正余数未在窗内全部观察。
  数值验证：5 级覆盖水平确认。

**定理 3（对称性，P231）**：生成侧优化器（不经过 MDL，直接在验证器反馈下迭代）
  同样收敛到影子行为——除非验证器包含有效性约束（防作弊检查）。
  实证：doubao round2 打出 1.030× "optimal"（不可能值），被 subset-validity 拦截。

**推论（收费站必然性）**：设 M 为任何评估指标、C 为真约束集。若推断/优化过程
  使用 M 作为目标且 H 中存在影子（M-等价但 C-违反），则推断/优化的输出
  以正概率是影子。**C∧V 门是唯一修复**——它对每条输出主张执行 C 的
  机械检查，影子因 C-违反被拦截。

## 命题 4（标签必要性，P245/P246/P249，正式化）

**设定**：有限行集 R，|R|=n；输出 h 的 C-违反集 E(h) ⊆ R；指标 M(h)=|E(h)|
（错误计数）；验证器每轮返回反馈 F_t；优化器第 t 轮视图 V_t = (h_t, F_1..F_t)
（含 cache 时）或 (F_1..F_t)（无 cache 时）；提议映射把视图映到下一输出。

### 4a-i 每轮信息上限（已证）

F_t = f∘M(h_t) 时：I(E(h_t); F_t) ≤ I(E(h_t); M(h_t)) ≤ H(M(h_t)) ≤ log₂(n+1)。
两次数据处理不等式（F 是 M 的函数；E→M 是函数）。即**标量通道每轮可携带的
"哪些行错"信息不超过 log₂(n+1) 比特，且与轮数无关**。

### 4a-ii 历史不累积（已证）

若视图只经 M 依赖输出（同基数 ⇒ 同视图），则给定历史的 E 后验只通过当前
|E(h_t)| 依赖于 E：**多轮标量反馈循环的信息内容 ≡ 单轮**——关于"哪些行错"
的可识别信息不随轮数增长。推论：修复不可累积，任何观测到的改进都来自
先验（固定提议），不来自循环。P240 rich1 臂实证：6 轮全部烧尽、流速
−0.639 bits/call、零收敛——与"循环无 accumulative 信息"一致且更强。

### 4a-iii 纤维内不可区分（纤维对称提议下已证）

提议映射纤维对称（同 M 的输出产生相同分布的下一 M）时，任意策略的期望错误
轨迹是 M-马尔可夫的，条件期望 E[|E_{t+1}| | 视图] 在纤维内为常数——**策略
无法把"修哪行"与"哪行真错"关联起来**；定向修复不可实现，观测改进只能
来自基数收缩（先验），非行级识别。

### 4b cache 可实现性（构造性证明）

设优化器状态含 (h_t, F_t)（cache），且 F_t ⊇ E(h_t)（标签反馈）。策略
σ："未被点名行保持，被点名行翻转"是 (h_t, F_t) 的函数——可实现，且保证
|E(h_{t+1})| ≤ |E(h_t)|（单调收敛），全披露时单轮清零。**无 cache 时 σ
不可实现**（转移核无法条件于"未点名行保持"）——P240 协议 v1 实测：全标签
+无 cache → 模型重掷本来正确的行，流速仍为负。cache = 优化器对自身当前
影子的唯一记忆。

### 推论（吞吐制度定理，连接 P233/P240/P249）

| 制度 | 每轮可识别信息 | 可累积 | 实测（P240） |
|---|---|---|---|
| 纯标量 | ≤ log₂(n+1) ≈ 3.7（n=12） | 否（4a-ii） | −0.639 bits/call |
| 行标签 | H(E_t\|历史)，单调递减 | 是（4b） | 5.9–6.7 bits/call，~2 轮收敛 |

P233 的 1.15 bits/call（发现回路，带行标签）位于标签制度上限之内——上限是
界不是效率；制度差异（P240 注册的 regime note）由本推论给出定理表述。
标签制度的生产函数从定理侧获得其形状：单调递减的几何收敛，非线性标度。

**状态**：4a-i/ii 无条件成立（信息论恒等式）；4a-iii 在纤维对称假设下成立
（非对称提议——例如利用行序的外部结构——可部分绕过，留作注记）；4b 构造性
成立。行为方向的"主动破坏"（负流速）保持为经验规律。非周期推广（T1 的
假设类泛化）仍开放。

**T3 状态修正（P244 第二实例未找到）**：kimi/deepseek × 3 轮（无有效性检查
条件下）全部直抵 1.000，零钻裂缝事件。T3 的"优化器钻 M 的裂缝"不是无条件的——
钻裂缝压力似依赖**优化器-任务能力缺口**（doubao-lite 到不了诚实最优才钻；
能到最优的模型无需作弊）。条件化假设（PROPOSE）：exploit 压力 ∝ 优化压力 ×
能力缺口。可检验预测：难任务 + 无有效性检查 + 到不了最优的模型 → 钻裂缝
复现；同任务 + 有效性检查 → 拦截。
