# 影子统一定理（Shadow Unified Theorem）

**状态**：框架已建立，数值验证完成（P225 精确恒等式 + P226 偏好定理 + P231 生成侧钻裂缝 + P232 收费站拦截）。论文脊柱。

## 定理陈述

**设定**：假设空间 H、真规则 r ∈ H、观察窗 W（有限样本集 S ⊂ 全域）、
MDL 选择器（按描述长度 + 经验误差字典序选规则）。

**定义**（影子规则）：h′ ∈ H 是 r 的影子，当且仅当
  (1) h′|W = r|W（窗内行为完全一致）
  (2) |h′| < |r|（描述更短）

**定理 1（影子必然性，P225）**：若 H 中存在 h′ 满足 (1)(2)，则任何有限窗 W 下影子数 > 0。
  对周期 m 分类任务：影子数 = 2^(m - |R(W)|)，其中 R(W) = 窗内观察到的余数类集合。
  数值验证：200/200 随机窗精确匹配。

**定理 2（偏好定理，P226）**：MDL 后验众数 = 最短影子 S_r ∩ R(W)。
  严格短于真规则当且仅当正余数未在窗内全部观察。
  数值验证：5 级覆盖水平确认。

**定理 3（对称性，P231）**：生成侧优化器（不经过 MDL，直接在验证器反馈下迭代）
  同样收敛到影子行为——除非验证器包含有效性约束（防作弊检查）。
  实证：doubao round2 打出 1.030× "optimal"（不可能值），被 subset-validity 拦截。

**推论（收费站必然性）**：设 M 为任何评估指标、C 为真约束集。若推断/优化过程
  使用 M 作为目标且 H 中存在影子（M-等价但 C-违反），则推断/优化的输出
  以正概率是影子。**C∧V 门是唯一修复**——它对每条输出主张执行 C 的
  机械检查，影子因 C-违反被拦截。

## 命题 4（标签必要性，P245/P246，一般形式）

**设定**：优化器（任意策略）产生序列 h_1, h_2, …；验证器每轮对 h_t 返回反馈
F(h_t)；E(h) ∈ 2^R 为 h 的 C-违反行集合（R = 有限行集）；M(h) = |R \ E(h)|/|R|
（标量分数）。记 I_t = I(E(h_t); F(h_t))。

**命题 4a（无标签上界）**：若 F 经 M 因子化（F = f∘M），则对任意策略
  E[|E(h_t)| − |E(h_{t+1})|] ≤ H(M(h_t)) ≤ log₂(错误档数)，
即每轮期望错误消除不超过标量分数通道的信息容量。M-纤维内所有 C-违反模式
对优化器不可区分——修复被压缩为纤维上的随机游走。

**证明草图**：F = f∘M 时，同纤维内两输出 h, h′ 满足 F(h)=F(h′)，故优化器的
转移核在给定反馈下对二者相同；策略能消除的错误至多等于它能*识别*的错误，
而每轮可识别的比特 ≤ I(E; F) ≤ H(M)（数据处理不等式）。P240 数值锚点：
rich1 臂 H(M) ≈ log₂13 ≈ 3.7 比特，流速实测 −0.639 bits/call（随机游走，
与"不可靠进展"一致且更强）；rich3/rich10 臂 F ⊇ E，I_t = H(E)，
界失效，逐行修复可达（~2 轮收敛，5.9–6.7 bits/call）。

**引理 4b（cache 必要性）**：若优化器状态不含其上一轮输出（无 cache），则
即使 F ⊇ E，"只修被点名行"的单调修复策略**不可实现**——转移核无法条件于
"未点名行保持不变"。P240 协议 v1 实测：全标签反馈 + 无 cache → 流速仍为负
（模型重掷本来正确的行）。生成骨架 state = ruleset + cache 的 cache 项
由此获得定理级动机：**cache = 优化器对自身当前影子的唯一记忆**。

**状态**：4a 的信息论方向已证（数据处理不等式，一般 H）；"流速为负"的
行为方向（主动破坏正确行）是经验规律非定理。4b 的可实现性论证同理：
协议课（实证）+ 可实现性（结构性论证）。两项的一般化版均待正式笔证。

**T3 状态修正（P244 第二实例未找到）**：kimi/deepseek × 3 轮（无有效性检查
条件下）全部直抵 1.000，零钻裂缝事件。T3 的"优化器钻 M 的裂缝"不是无条件的——
钻裂缝压力似依赖**优化器-任务能力缺口**（doubao-lite 到不了诚实最优才钻；
能到最优的模型无需作弊）。条件化假设（PROPOSE）：exploit 压力 ∝ 优化压力 ×
能力缺口。可检验预测：难任务 + 无有效性检查 + 到不了最优的模型 → 钻裂缝
复现；同任务 + 有效性检查 → 拦截。
