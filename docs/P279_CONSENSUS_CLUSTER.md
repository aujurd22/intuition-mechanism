# P279: 共识簇聚合——把"多数表决"放进模板层，能修好薄板吗？

**状态**：已完成（2026-10-26），**PASS 4 / FAIL 1，总体 MIXED**。
`p279_verdict.json` 为机读结论，`p279_preregistration.json` 为跑前注册（冻结）。
**诚实标签：in-sample 再分析**——规则是在看过 P278 的 112 次模板测量之后设计的，
所以它不是前瞻性检验；前瞻性检验是 P280（冻结规则，换新场景）。

## 问题

P278 的结论是：14 行里**每一行都至少有一个模板落在真值视差 ±5 px 内**，但全模板
中位数在薄板上取了背景值（rel 0.2963）。若"物体模板是少数、中位数把它投掉"这个
解释成立，那么改成"取最大的相互一致簇（plurality）"就应该修好它，并且不该弄坏对照。

## 设计（零模型调用、零图像匹配）

纯算术：输入是已冻结的 `out/p278/p278_raw.json`（sha256 钉死），GT 沿用 P277 记录值。

| 臂 | 规则 |
|---|---|
| R1 基线 | 全部有效模板的中位数（P278 的估计器，此处重算对照） |
| R2 共识簇 | 有效模板视差按 ≤5 px 单链接聚类；取成员最多的簇；并列时取平均 NCC 更高者，再并列取中位更低者；估计 = 该簇中位数 |
| R3 负对照 | 每行随机取一个有效模板（seed 20261026） |
| R4 NCC 单点 | 取 NCC 最高的那个模板 |

有效性条款：视差 <0 无效（正基线校正立体不可能）；有效模板 <2 的行不可评估。

## 预注册判据与结果

| 预言 | 判定 | 数字 |
|---|---|---|
| P279-1 薄板修好（R2 < 0.15） | **PASS** | 0.2963 → **0.0059**（选中簇 `[71,72,72,71]`，中位 **71.5**，GT 71.1） |
| P279-2 无回归（11 条可评估对照全过，偏移 ≤5%） | **PASS** | 回归 0；最大深度偏移 **3.33%** |
| P279-3 **注册负预言**：木块不该被修好（R2 ≥ 0.15） | **PASS（预言成立）** | 有效样本只剩 `{71, 421}` 两个单点；并列按 NCC 取 421（0.617 vs 0.571）→ rel **0.835** |
| P279-4 负对照：随机取模板应失败 ≥3 条对照 | **FAIL** | 随机只失败 **1/11**（Aloe）——对照队列太容易，随机也能过 |
| P279-5 机制：薄板选中簇 ≥3 成员且中位在真值 15% 内 | **PASS** | 4 成员，中位 71.5 vs GT 71.1（差 0.6%） |

## 读法

1. **"物体是少数但不是孤例"这个解释成立**：薄板的 9 个模板里，物体模板（71/72）
   出现 4 次，背景层（101）2 次，更远层（211-220）3 次。中位数取第 5 个值 → 101；
   取最大簇 → 71.5。差别不在估计器的算术，在**投票规则**。
2. **木块的失败是结构性的，不是规则缺陷**：它的 bbox 只有 101 px 宽，只放得下 3 个
   模板，其中 1 个是物理上不可能的 −18 px。剔掉后只剩两个单点，任何"聚合"都只能
   二选一。**这不是该用更多规则去修的 Bug，而是"采样数不足"**——修法是更密的候选
   网格（多尺度/多尺寸模板）或物体掩码。
3. **P279-4 的 FAIL 削弱了 P279-2 的证据力**：11 条对照里有 10 条随机抽取也能过，
   说明这批对照对规则不敏感。所以"共识簇无回归"目前是**弱证据**；真正的证据是
   薄板从 0.2963 到 0.0059、以及木块按预言保持失败。要拿到强证据，必须换更难的
   场景（P280）。
