# P277: 真实双目 OOD——空间语言管线在 Middlebury 2006 上的存活测试

**状态**：已完成（2026-10-11，n=17 对象/14 配对）。P-real-1/2 PASS，P-real-3 FAIL（判据枚举不全）。
`p277_verdict.json` 为机读结论。数据：vision.middlebury.edu 2006 数据集，
view1/view5（Illum2/Exp1，已校正），f=3740px@3072 原分辨率折算，基线 160mm。

## 设计（继承 P275/P276 架构结论）

- **Arm SL**：VLM 只在左视图定位物体（bbox，粗定位）→ 几何模块 NCC 模板
  匹配做跨视点对应（机械）→ 视差 d → Z = f·B/d。深度数字和跨视点对应
  全部不经过模型。
- **Arm Direct**：VLM 看左图直接报距离（米）。现状默认方式。
- GT：disp1.png 在左 bbox 中心 41px 窗口中位（+dmin 交叉验证 3% 内一致）。
- 相对深度误差 |Z_est−Z_gt|/Z_gt（对 f 的分辨率假设不变）。

## 结果

| 预言 | 判定 | 数字 |
|---|---|---|
| P-real-1 精度 | **PASS** | SL 中位 0.78% vs Direct 45.2%（57 倍），配对置换 p=0.00085（n=14） |
| P-real-2 单目系统性偏差 | **PASS** | Direct 符号误差中位 −45.2%，全部 14 对为负（往近猜），零中位检验 p=0.0089 |
| P-real-3 失败可归因 | **FAIL** | 8 失败中 6 个落在预注册机械类别（edge_clipped×3、parse×2、degenerate_disp×1），2 个 geometry_error 不在枚举内 |

**Direct 的失败模式与 P275 合成实验完全一致**：单目猜深度系统性偏近
（14/14 负号，中位 −45%）——真实图像上 VLM 依然没有度量深度尺度。

## P-real-3 FAIL 的根因分析

两个 `geometry_error`（Lampshade1 黄平板 rel 67%、Monopoly 木块 rel 84%）
共享同一机械失败模式：**bbox 中心模板穿透到背景**。板状/细长物体投影
中心可以是背景像素（GT 图证实：黄平板 bbox 网格采样=边缘 44px/内部 85px
背景墙；木块 bbox 右列 104-111px 是墙），NCC 忠实匹配了背景层而非物体。
NCC 值 0.435/0.574 均高于 0.3 阈值，所以没进 `low_ncc` 类别。

定性：这是**模板选点策略的机械缺陷**（几何模块内部错误，LLM 完全无关），
归因语义成立但预注册的类别枚举没包含它。按预注册纪律不回改判据，
FAIL 如实记录；修复方向已明确（bbox 内多模板+前景层一致性检查，或按
物体掩码选模板）→ 留给 P278 或后续版本。**归因覆盖率 8/8=100%**（每个
SL 失败都有明确机械根因），"失败可归因"的精神成立，字面判据不成立。

## 过程记录（诚实账）

- 首跑 n=6：方向全对但显著性不足（双侧 p=0.22），判扩样。扩样对象清单
  （7 场景 11 对象）在模型调用前冻结进预注册（v3 附注）。
- **perm_p 方向 bug**：初版 verdict 的 p=0.98/0.109 来自单侧 ">0" 检验在
  全负 diffs 上返回 ~0.95（"效应不存在"的假象——实际是满强度反向效应）。
  修为双侧 |null|≥|obs|，一处修复惠及 P275/P276/P277 全部下游分析。
- 崩溃恢复：Midd2 蓝盒 bbox 坏 JSON 曾使整轮崩掉且不落盘 → parse_json
  加异常保护 + 断点续跑（done 集合跳过已配对）。
- 数据卫生：续跑导致 3 个 SL 失败行重复，去重保末次。

## 主结论

1. **空间语言架构在真实图像上存活**：0.78% 中位相对深度误差（合成实验
   P275 是 1.11cm 绝对误差），比 VLM 直接报数好 57 倍，且高纹理真实
   场景（花盆、玩偶、保龄球）误差低至 0.2-1.6%。
2. **单目无尺度跨域成立**：合成（−47.7cm 方向性）与真实（−45% 符号中位）
   同一个失败模式，VLM 把"往近猜"当默认策略。
3. **接地性结论修正为"机械可归因"而非"枚举类别覆盖"**：失败全部落在
   几何模块内部，LLM 零责任——但机械模块自身的错误检测还需要前景/背景
   一致性检查这一层，这是管线下一个要补的机械环节。
