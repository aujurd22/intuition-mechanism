# G2B：可学会域重设计（"星语"形态域）— 设计规格 + 预注册

**状态**：包已建，预注册已写入（2026-10-04，**先于任何人类施测**）。
对应评审 round-6 第 0 号缺口的路线 (a)；P235 的路线 (b)（数论训练被试）保留待招。

## 一、设计目标（评审原话的落地）

1. 人与模型从**同一批示例**出发，人 **25 分钟内可习得**；
2. 真值**程序化**（`generate_stems.py::truth` 是纯函数，无歧义）；
3. 保留 P234 预注册预测的**两轴结构**：表面形式（词形记忆 = "d 绑定"类比物）
   + 紧凑结构规则（双特征配对 = "特征表"类比物）；
4. 遮蔽考试保留全部信息但**破坏表面绑定**（密码字母表+对照表）——
   记忆者崩、结构者过。

## 二、域规格

刺激：CVC 假词。字母表 = {b,d,g,k,p,t,a,i,u}。
- **首字母**：无关特征（必须被学习者发现无关；含"陷阱词"——首字母浊清与词尾不同类）
- **元音 a=开口 / i,u=闭口**（特征 B，类比 d mod 3）
- **词尾 b,d,g=浊 / k,p,t=清**（特征 A，类比 d mod 4）

复数规则（特征**配对**的函数，类比 χ\*(d mod 3, d mod 4)）：

| | 开口 (a) | 闭口 (i,u) |
|---|---|---|
| **浊尾** | -um | -is |
| **清尾** | -is | -ok |

两个 -is 落在反对角：**任何单特征规则上限 0.5**，只有配对规则到 1.0。
机遇水平 = 1/3。

条目集（固定、已注册，人与 LLM 完全相同）：
train 16（每格 4，含 3 个首字母陷阱词）；exam1 12（迁移+自觉，5 个陷阱）；
exam2 8（密码遮蔽，密码表随卷提供，1 个陷阱）。见 `g2b_package/answer_key.json`。

**附加设计预测**（新增，同样预注册）：
- (P-a) 学习相成功率：多数被试（n≥5 中 ≥4）在 25 分钟内自报掌握且 exam1 ≥ 8/12
  ——这是"可学会"的设计验收线；达不到则域还需再设计。
- (P-b) 陷阱词（首字母误导）错误率高于非陷阱词（首字母无关性是最后被习得的特征）。
- (P-c) exam2 与 exam1 的准确率差 < 0.25（结构学习者应几乎无损跨表面形式）。
