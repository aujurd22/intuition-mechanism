# PAPER v2 — 脊柱、证据表与缺口清单

**状态**：计划（2026-10-26），由 registry 审计当日产出。
**与 `docs/PAPER.md` 的关系**：PAPER.md 是 2026-09-27 的骨架 v1，它的脊柱是
"L1 识别 / L2 去干扰 / L3 盲发现"的三级发现阶梯；那份骨架**早于**影子统一定理
（`docs/SHADOW_UNIFIED_THEOREM.md`，2026-10-05）和 10-05→10-11 的三条新线
（P259 的头牌外部靶、P269–P277 的声带/空间线）。v2 换脊柱：**L1/L2/L3 降级为
"发现线"的一节背景**，论文的主张改为下面四条。PAPER.md 的 Part I / Part II 内容
仍然有效，作为 §4–§5 的素材复用，不重写实验。

**为什么换**：L1/L2/L3 是"我们测出了什么"的分类，不是读者会带走的东西；而
"直觉可被机械化到什么程度、它的边界在哪、怎么机械地拦截它冒充洞见"是一条
读者能带走的主张，且 268→277 行数据里有四处独立证据支撑它。

---

## 1. 一句话主张

> **直觉机械化 = 验证器 + 校准门。**
> 看起来像洞见的东西，只有满足"可压缩、可验证、可迁移、非平凡"四条件才成立；
> 不满足却骗过了评分函数的东西是**影子**（shadow）——它在度量 M 下完美、
> 在真约束 C 下违规。C∧V 门（约束+验证）能在它到达用户之前拦截它。
> 论文的贡献不是"AI 有直觉"，而是**这条边界是可测量、可机械执行的，并且我们
> 在四个域（数论、判断基准、语言渲染、真实双目空间）上把它测了一遍。**

## 2. 四条承重主张

### C1 影子统一定理（论文脊梁）
- **主张**：给定度量 M 与真约束 C 不重合，推理与优化都会收敛到影子（在 M 下看起来
  完美、违反 C 的规则）；唯一修法是同时检查 C 的验证器（C∧V 门）。
- **机制侧的三条独立来源**：判断侧（模型自述规则当代码执行只有 ~50 分＝纯恐）／
  生成侧（给打分函数的优化器报出 1.030×，高于理论上限，是漏洞不是能力）／
  中间件侧（收费站 live case：坏断言被拦、陷阱句降级、甚至纠正了模型的假阴性）。
- **硬内容**：影子计数有精确闭式（200 个随机窗口校核）；MDL 后验众数恰是最短影子；
  判断侧加厚到 41 规则 × 3 模型后接近饱和（0.90–0.93，无模型分离）——这条实验线
  **已关闭**。
- **证据**：`docs/SHADOW_UNIFIED_THEOREM.md`（命题 4/5）；行 P232（
  `experiments/p232_rules_truth.json`、`experiments/p232_middleware_demo.json`）。
- **边界**：定理是"形状论断 + 三条独立实例 + 两个可算量"，不是普适测度论定理；
  写的时候必须把"我们证明了什么"与"我们观察到三次"分开。

### C2 四态收费站（可执行的产物）
- **主张**：每条 LLM 断言出站时只允许四种状态——VERIFIED（机械验证+证据）／
  REFUTED（拦截）／ABSTAIN／SPECULATION（新颖但未验证，**标注后放行**，不静默）。
  拦截不是终态：REFUTED 的证据回喂模型重生成（最多 3 轮），只有带证据的
  VERIFIED 或带机械证据的 ABSTAIN 可到达用户。
- **证据**：`hallucination_gate/README.md`；行 P270（`p270_verdict.json`：收费站抓到
  新错误类——坐标系不匹配的预测，结构自洽但 27 个精度全 0）、P271
  （九项升级 13/13 smoke test，`test_plugins_v3.py`）。
- **边界**：P270 的 H1 本轮**不可答**（证据缺坐标系去修坐标系错误），nogate 对照
  因文件锁丢数据、配对比较作废——这两条要在论文里当限制写明，不能当"已验证"。
- **注意**：SPECULATION 放行是设计决定（在洞见前沿，真新颖与幻觉行为上不可分），
  必须配预测台账（`hallucination_gate/preamble_ledger.py`）留下可对账的承诺。

### C3 语言化鸿沟（最反直觉、最好写的一条）
- **主张**：直觉知识与语言能力**部分脱钩**。模型把判题规则说成语言再执行，复杂规则
  只有 25–50 分；但它的实际判断有 ~90 分。推论是架构性的：**直觉核可以输出判断／
  置信度／证据指针，不可以可靠输出"我按什么规律想的"**——所以任何"直觉快速出语言"
  的架构必须绕开内省，让语言层只渲染定稿判断。
- **证据**：行 P170–P184（登记在册）；P272（`p272_vocalizer_demo.json`：机械核
  0.4–1.0 ms + 渲染 0.7–1.4 s，978 近整数陷阱渲染成诚实的不确定）；P273
  （权威件 `p273_value_scale_analysis.json`：渲染层**值级幻觉 0/3 层**，而内省解释
  2/3，L3 在 22.4 s 后把数字揉成 `13571317`）；P274（
  `p274_offline_render.json`：本地 0.6B 渲染层，310–781 ms，零网络，零值级幻觉）。
- **边界**：渲染层呈模板级（重复），只够渲染判定、不够写文章；"完全无 transformer
  的第三级"仍是开放问题，不是本论文的主张。

### C4 域边界定律（诚实的负结果，也是防线）
- **主张**：真值不可机械判定的域，直觉核**永远沉默**（落进 SPECULATION+扫描候选，
  不伪装成直觉）。范围扩展只有两条已知机制：写更多验证器程序（工程），或等一次
  自发跃迁（不可控）。
- **证据**：G6 五次排除 + P268 静态/方向/曲率全等 + **P269 的关键负结果**：n=11 的
  细网格曲率信号（11/13 窗口）在 n=30 扩样后翻盘——比值几何均值 0.97，等于抛硬币；
  fine-grid null 在 n=30 站住。差异信号**只在功能层**存活（P265 更新-目标对齐
  r=0.51；P247 输出行为 r=0.854），所有表示/几何/曲率测度在任何粒度都拉平。
- **证据文件**：`p269_curvature_verdict.json`、`experiments/p265_verdict.json`。
- **论文用法**：这一条是"我们不是在建一个万能的直觉神话"的证明；把它放在
  Limitations 之前，作为 contribution 之一（可测量的边界）。

## 4. 外部锚（审稿人最先看这几条）

1. **FunSearch 官方 benchmark**：OR3/Weibull-5k 逐字取自官方 notebook；两个模型独立
   发现启发式同时打赢 First-Fit 与 Best-Fit，且迁移到没见过的 Weibull-5k；
   模拟器等价性 25/25 核过。**必须写明**：Nature 论文的精确启发式未公开，比较对象
   是官方仓库工件。
2. **对 Jev（训练式 System-One 判别器）的定位**：共享数据集（SMS Spam, n=200）上
   零样本 LLM judge 与其打平（96.0–97.0 vs 96.5）；我们的 pack 加置信门后
   97.5% @ 99.5% 精度 / 91% 覆盖（Jev：95.5% / 63%）；验证器覆盖域机械层
   100% @ ECE 0.0075、$0、0.37 ms。**不许写成"我们更强"**——它是广度（37 数据集、
   432 ms 前向），我们是"蒸馏源 + 校准夹具"。
3. **CWZ 勘误**：机械管线抓到的已发表数字错误（43/238 vs 143/238）——这是"验证器
   不是装饰"的最好证据。
4. **人机对照表**：写，但 n=1（作者本人）必须写在正文而非脚注。
